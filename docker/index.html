Nasıl Çalışır

3 Adımda Güvenlik.

📸
Snapshot Al
Güncelleme, config değişikliği, yeni paket — öncesinde bir snapshot. Btrfs'te sıfır saniyede tamamlanır.
🔧
İstediğini Yap
Dene, boz, keşfet. Korkmadan. Sistemi deneme alanı olarak kullan — snapshot senin güvencen.
⏮
Geri Dön
Tek komut veya GUI'den tek tıkla. Yeniden başlatmada restore uygulanır. Her şey eski haline döner.

GTK4 Arayüz

Hangi Backend?

rollbackx — backend karşılaştırma
Backend Ne Zaman? Hız
Btrfs
Btrfs disk varsa Anlık (~0ms)
LVM Thin
LVM Thin volume varsa Çok hızlı
Rsync
ext4 dahil her şey Normal

RollbackX sisteminizi otomatik olarak algılar, en uygun backend'i seçer.

Kurulum

Dakikalar içinde hazır.

# .deb paketini indir ve kur $ wget http://68.183.213.255/releases/rollbackx_0.1.0-1_amd64.deb $ sudo dpkg -i rollbackx_0.1.0-1_amd64.deb $ sudo apt install -f # bağımlılıkları tamamla # Başlat $ rollbackx-gtk # GTK arayüz $ rollbackx --help # CLI
# Hızlı kurulum scripti (yakında) $ curl -fsSL http://68.183.213.255/get.sh | sudo bash # Kurulum tamamlandı: $ rollbackx kontrol # sistemi kontrol et $ rollbackx snapshot listele # snapshot'ları gör
# Kaynaktan derle (Pardus/Debian) $ git clone https://github.com/rollbackx/rollbackx $ cd rollbackx $ bash scripts/build-release.sh # gerekli paketleri kurar, derler $ sudo dpkg -i rollbackx_0.1.0_amd64.deb
